# Weibull Lab

Веб-приложение для работы с нечёткими величинами на основе распределения Вейбулла.
Практическая работа по дисциплине «Неклассические логики», вариант 8.

Backend: Python 3.12, FastAPI, NumPy. Frontend: HTML, CSS и JavaScript.

## Возможности

- Задание и изменение параметров нечётких величин, графики функций принадлежности.
- Сложение, вычитание, умножение, деление и сравнение по центроидам.
- Генерация 100–300 величин с независимыми параметрами: γ из [1; 6), σ из [0,5; 10), сдвиг 0. Готовые группы в генераторе не задаются.
- Новый случайный seed по умолчанию; воспроизведение набора по явному seed, включая 0.
- Кластеризация k-means с заданным k либо одиночная связь по порогу расстояния.
- Сравнение всей формы, центроидов либо срезов выбранного уровня α.
- Сохранение и импорт JSON, экспорт CSV и журнала эксперимента.

## Запуск через Docker

Запустите Docker Desktop с Linux containers. Из корня проекта выполните:

```sh
docker compose up --build --wait
```

Откройте [http://localhost:8080](http://localhost:8080).
В Windows доступны `START.cmd` и `STOP.cmd`.
При первой сборке требуется интернет для загрузки образа и зависимостей.
Тесты ядра и API выполняются при сборке образа.

Остановка: `docker compose down`. Логи: `docker compose logs -f web`.
Если порт занят, скопируйте `.env.example` в `.env` и измените `WEIBULL_PORT`.

## Запуск без Docker

Требуется Python 3.12 или новее:

```sh
python -m pip install -r requirements.txt
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8080
```

Открывайте приложение по адресу сервера. Запуск `index.html` через file:// не заменяет API.

## Как пользоваться

1. В «Обзоре» задайте размер набора и нажмите «Сгенерировать набор». Для повтора снимите флажок «Новый случайный seed» и введите сохранённый seed.
2. Выберите метрику и режим анализа, задайте k либо порог и нажмите «Выполнить анализ».
3. Для отсечения выберите «Отсечение по уровню α», введите α от 0,000001 до 1 и повторите анализ. Сравниваются границы интервалов, где μ(x) ≥ α. Уровень α и порог расстояния — разные параметры.
4. В разделе операций задайте величины A и B и выберите действие. Деление отклоняется, если представленный срез делителя содержит ноль.
5. Перед закрытием вкладки скачайте JSON: данные находятся в памяти браузера. Импорт восстанавливает данные и настройки, анализ пересчитывается на сервере.

## Структура

- `backend/fuzzy.py` — нормировка, срезы, центроиды, арифметика и генерация.
- `backend/clustering.py` — k-means, одиночная связь, расстояния и силуэт.
- `backend/main.py` — HTTP API, проверка входных данных, раздача интерфейса.
- `index.html`, `styles.css`, `app.js` — интерфейс и графики.
- `tests/test_backend.py` — тесты математического ядра и API.
- `tests/ui.test.cjs` — браузерный сценарий Playwright.
- `examples/build_demo.py` — создание демонстрационных JSON и журнала: `python -m examples.build_demo`.

## Проверки

```sh
python -m pip install -r requirements-test.txt
python -m unittest discover -s tests -p "test_*.py" -v
```

Браузерный тест требует Playwright, запущенный сервер и при необходимости переменные `BROWSER_PATH`, `PLAYWRIGHT_MODULE`, `APP_URL`.

API: [http://localhost:8080/api/docs](http://localhost:8080/api/docs).
Проверка готовности: `/healthz`.

Используется конечная сетка из 101 α-среза с ε=10⁻⁶. Промежуточные срезы интерполируются; центроид вычисляется приближённо. Значения принадлежности не являются вероятностями. Кластеризация жёсткая: каждый объект относится ровно к одной группе.

В репозиторий входят исходный код, конфигурация и тесты. Персональные отчёты, задание и сгенерированные материалы не публикуются.
