Функция принадлежности Вейбулла

μ(x) = f(x) / f(xmax) ∈ [0; 1]
f(x) = (γ / σ) · ((x − a) / σ)γ − 1 · exp[−((x − a) / σ)γ], x > a

Максимум плотности достигается при xmax = a + σ · ((γ − 1) / γ)1 / γ для γ > 1. При γ = 1: μ(x) = exp[−(x − a) / σ] для x ≥ a.

При x < a принадлежность равна 0; в точке x = a она равна 0 при γ > 1 и 1 при γ = 1.

γ — гамма: форма; σ — сигма: масштаб, σ > 0; a — а: сдвиг. μ — мю: степень принадлежности, а не вероятность. Значение 1 соответствует вершине кривой.
